01 — Core Insight

LinkedList: Pointer Surgery

Every LinkedList problem reduces to manipulating the next pointers without losing your place. The most common mistake is reassigning a pointer before saving the reference you still need. Draw the list, identify which pointers change, and save them before you overwrite.

The Core Insight: Use a dummy head node to eliminate edge cases at the front of the list. Instead of special-casing "what if the head is removed?", prepend a dummy node and always return dummy.next. This single habit solves 90% of pointer-management bugs.

Node Structure

// Standard singly linked list node
class ListNode {
    int val;
    ListNode next;
    ListNode(int val) { this.val = val; }
}

// Doubly linked list node
class DListNode {
    int val;
    DListNode prev, next;
}
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
02 — The 4 Patterns

LinkedList Patterns

Pattern 1 · Fast & Slow Pointers

Two pointers that move at different speeds. Fast moves 2 steps, slow moves 1. When fast reaches the end, slow is at the middle. When fast meets slow again, there's a cycle.

Why it works: In a cycle of length L, fast gains one step on slow per iteration. They must meet within L steps — like two runners on a circular track. Floyd's algorithm is the gold standard for cycle detection.

// Detect cycle (LC 141)
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}

// Find middle node (LC 876)
public ListNode middleNode(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow; // at middle when fast hits end
}
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast: return True
    return False

def middle_node(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow
Pattern 2 · Reversal

The classic three-pointer reversal. Save next, flip the arrow, advance. The iterative version is O(1) space; the recursive version is elegant but O(n) stack space.

Common bug: Saving prev but forgetting to update it. The three assignments must happen in this order every iteration: next = curr.next → curr.next = prev → prev = curr → curr = next.

// Reverse entire list (LC 206)
public ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next; // 1. save next
        curr.next = prev;          // 2. flip arrow
        prev = curr;               // 3. advance prev
        curr = next;               // 4. advance curr
    }
    return prev;
}

// Reverse sublist from left to right (LC 92)
public ListNode reverseBetween(ListNode head, int left, int right) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode pre = dummy;
    for (int i = 1; i < left; i++) pre = pre.next;
    ListNode curr = pre.next;
    for (int i = 0; i < right - left; i++) {
        ListNode next = curr.next;
        curr.next = next.next;
        next.next = pre.next;
        pre.next = next;
    }
    return dummy.next;
}
def reverse_list(head):
    prev, curr = None, head
    while curr:
        nxt = curr.next   # 1. save next
        curr.next = prev  # 2. flip
        prev = curr       # 3. advance prev
        curr = nxt        # 4. advance curr
    return prev
Pattern 3 · Merge & Sort
// Merge two sorted lists (LC 21)
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0); // dummy head eliminates edge cases
    ListNode curr = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) { curr.next = l1; l1 = l1.next; }
        else                   { curr.next = l2; l2 = l2.next; }
        curr = curr.next;
    }
    curr.next = (l1 != null) ? l1 : l2; // attach remaining
    return dummy.next;
}
def merge_two_lists(l1, l2):
    dummy = curr = ListNode(0)
    while l1 and l2:
        if l1.val <= l2.val: curr.next = l1; l1 = l1.next
        else:                curr.next = l2; l2 = l2.next
        curr = curr.next
    curr.next = l1 or l2
    return dummy.next
Pattern 4 · Remove / Nth from End
// Remove Nth node from end (LC 19) — one pass
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode fast = dummy, slow = dummy;
    for (int i = 0; i <= n; i++) fast = fast.next; // gap of n+1
    while (fast != null) { fast = fast.next; slow = slow.next; }
    slow.next = slow.next.next; // skip the nth node
    return dummy.next;
}
def remove_nth_from_end(head, n):
    dummy = ListNode(0)
    dummy.next = head
    fast = slow = dummy
    for _ in range(n + 1): fast = fast.next
    while fast:
        fast = fast.next
        slow = slow.next
    slow.next = slow.next.next
    return dummy.next

LinkedList Problems Worth Studying

LC 25 · Reverse Nodes in K-Group Hard

Reverse every group of k nodes. If fewer than k remain, leave them as-is. Requires careful pointer management: find the k-th node, reverse the group, reconnect.

Key insight: Check if k nodes remain before reversing. Use a helper to reverse k nodes and return the new head and the node after the group. Recursively attach the result of the next group.

public ListNode reverseKGroup(ListNode head, int k) {
    ListNode curr = head;
    int count = 0;
    while (curr != null && count < k) { curr = curr.next; count++; }
    if (count < k) return head; // fewer than k nodes remain
    ListNode prev = null, node = head;
    for (int i = 0; i < k; i++) {
        ListNode next = node.next;
        node.next = prev; prev = node; node = next;
    }
    head.next = reverseKGroup(node, k); // head is now tail of reversed group
    return prev;
}
def reverse_k_group(head, k):
    curr, count = head, 0
    while curr and count < k:
        curr = curr.next; count += 1
    if count < k: return head
    prev, node = None, head
    for _ in range(k):
        nxt = node.next; node.next = prev; prev = node; node = nxt
    head.next = reverse_k_group(node, k)
    return prev
LC 142 · Linked List Cycle II Medium

Find the exact node where a cycle begins. After Floyd's detection (slow meets fast), reset one pointer to head, then advance both by 1. They meet at the cycle entrance.

Mathematical proof: When fast and slow meet inside the cycle, the distance from head to cycle entrance equals the distance from the meeting point to cycle entrance (going forward). So pointer from head + pointer from meeting point both reach entrance at the same step.

01 — Core Insight

Binary Trees: Think Recursively

Every tree problem decomposes the same way: what do I need from my left child, what do I need from my right child, and how do I combine them with my current node? If you can answer that, you can write the recursive solution.

The Core Insight: A binary tree IS recursion — the left subtree and right subtree are themselves binary trees. Trust the recursive call to return the correct answer for the subtree. Your only job at each node is to combine those two answers correctly with the current node's value.

Node Structure & Traversals

class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int val) { this.val = val; }
}

// Inorder: left → root → right  (gives sorted order in BST)
void inorder(TreeNode root) {
    if (root == null) return;
    inorder(root.left);
    process(root.val);
    inorder(root.right);
}

// Postorder: left → right → root  (good for deletion, heights)
// Level-order: BFS with a queue

    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

02 — The 4 Patterns

Binary Tree Patterns

Pattern 1 · Recursive Aggregation (Height / Diameter)

Post-order recursion: compute answers for both subtrees, combine at current node. Height and diameter are the canonical examples — height propagates upward, diameter is computed at every node.

// Diameter = longest path between any two nodes (LC 543)
int maxDiameter = 0;

public int diameterOfBinaryTree(TreeNode root) {
    height(root);
    return maxDiameter;
}

private int height(TreeNode node) {
    if (node == null) return 0;
    int left  = height(node.left);
    int right = height(node.right);
    maxDiameter = Math.max(maxDiameter, left + right); // diameter at this node
    return 1 + Math.max(left, right);                 // height propagates up
}
def diameter_of_binary_tree(root):
    res = [0]
    def height(node):
        if not node: return 0
        l, r = height(node.left), height(node.right)
        res[0] = max(res[0], l + r)
        return 1 + max(l, r)
    height(root)
    return res[0]
Pattern 2 · Path Problems (Max Path Sum)

Two return values in one: When solving path problems, your recursive function returns the best single branch going down (for the parent to extend), but updates a global max that counts both branches at once (paths that go through this node). Never confuse these two values.

// Binary Tree Maximum Path Sum (LC 124)
int maxSum = Integer.MIN_VALUE;

public int maxPathSum(TreeNode root) {
    dfs(root);
    return maxSum;
}

private int dfs(TreeNode node) {
    if (node == null) return 0;
    int left  = Math.max(0, dfs(node.left));  // ignore negative branches
    int right = Math.max(0, dfs(node.right));
    maxSum = Math.max(maxSum, node.val + left + right); // path through node
    return node.val + Math.max(left, right); // single best branch upward
}
def max_path_sum(root):
    res = [float('-inf')]
    def dfs(node):
        if not node: return 0
        l = max(0, dfs(node.left))
        r = max(0, dfs(node.right))
        res[0] = max(res[0], node.val + l + r)
        return node.val + max(l, r)
    dfs(root)
    return res[0]
Pattern 3 · Level-Order BFS
// Level order traversal (LC 102) — captures each level
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Deque<TreeNode> q = new ArrayDeque<>();
    q.offer(root);
    while (!q.isEmpty()) {
        int size = q.size();
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = q.poll();
            level.add(node.val);
            if (node.left  != null) q.offer(node.left);
            if (node.right != null) q.offer(node.right);
        }
        res.add(level);
    }
    return res;
}
from collections import deque

def level_order(root):
    if not root: return []
    q, res = deque([root]), []
    while q:
        level = []
        for _ in range(len(q)):
            node = q.popleft()
            level.append(node.val)
            if node.left:  q.append(node.left)
            if node.right: q.append(node.right)
        res.append(level)
    return res
Pattern 4 · BST Properties

In a BST, inorder traversal gives sorted order. Use this to validate, find kth smallest, and convert to/from sorted arrays. The constraint left < root < right applies to the entire subtree, not just immediate children — pass bounds down recursively.

// Validate BST (LC 98) — pass bounds down
public boolean isValidBST(TreeNode root) {
    return validate(root, null, null);
}
private boolean validate(TreeNode node, Integer min, Integer max) {
    if (node == null) return true;
    if (min != null && node.val <= min) return false;
    if (max != null && node.val >= max) return false;
    return validate(node.left, min, node.val)
        && validate(node.right, node.val, max);
}
def is_valid_bst(root):
    def validate(node, lo, hi):
        if not node: return True
        if not (lo < node.val < hi): return False
        return (validate(node.left, lo, node.val) and
                validate(node.right, node.val, hi))
    return validate(root, float('-inf'), float('inf'))

Tree Problems Worth Studying

LC 124 · Binary Tree Maximum Path Sum Hard

Find the path with the maximum sum. Paths can start and end at any node. The key: distinguish between "best gain going up to parent" and "best path through this node."

Common mistake: Returning left + right + node.val to the parent. That would mean the path goes down-left AND down-right, making a V-shape — you can't continue upward from a V. Return only the best single arm: node.val + max(left, right).

LC 297 · Serialize and Deserialize Binary Tree Hard

Encode a tree to a string and decode it back. Preorder with null markers is the cleanest approach — the null markers uniquely reconstruct the tree's structure.

// Serialize: preorder, null as "N"
public String serialize(TreeNode root) {
    if (root == null) return "N,";
    return root.val + "," + serialize(root.left) + serialize(root.right);
}

// Deserialize using a queue of tokens
public TreeNode deserialize(String data) {
    Queue<String> q = new LinkedList<>(Arrays.asList(data.split(",")));
    return build(q);
}
private TreeNode build(Queue<String> q) {
    String val = q.poll();
    if ("N".equals(val)) return null;
    TreeNode node = new TreeNode(Integer.parseInt(val));
    node.left  = build(q);
    node.right = build(q);
    return node;
}
def serialize(root):
    if not root: return "N,"
    return str(root.val) + "," + serialize(root.left) + serialize(root.right)

def deserialize(data):
    tokens = iter(data.split(","))
    def build():
        val = next(tokens)
        if val == "N": return None
        node = TreeNode(int(val))
        node.left  = build()
        node.right = build()
        return node
    return build()

01 — Core Insight

Graphs: Everything is BFS or DFS

Nearly every graph problem is solved by BFS for shortest paths and level-by-level problems, or DFS for connectivity, cycles, and exhaustive search. The key decisions are: directed or undirected? Weighted or unweighted? Then pick the traversal.

The Core Insight: A graph problem in disguise is still a graph problem. Grid problems (islands, paths in a matrix) are graphs where each cell is a node and edges connect neighbors. Word ladders are graphs where words are nodes and single-letter-differences are edges. Once you model it, BFS or DFS does the rest.

Graph Representations

// Adjacency List (most common for interviews)

02 — The 4 Patterns

Graph Patterns

Pattern 1 · BFS — Shortest Path / Level-by-Level

BFS guarantees the shortest path in unweighted graphs. The moment you visit a node in BFS, you have found the shortest path to it. A visited set prevents revisiting.

// BFS shortest path — returns distance from src to dst
public int bfsDistance(Map<Integer,List<Integer>> graph, int src, int dst) {
    Set<Integer> visited = new HashSet<>();
    Deque<int[]> q = new ArrayDeque<>();
    q.offer(new int[]{src, 0}); // [node, distance]
    visited.add(src);
    while (!q.isEmpty()) {
        int[] curr = q.poll();
        if (curr[0] == dst) return curr[1];
        for (int nei : graph.getOrDefault(curr[0], Collections.emptyList())) {
            if (visited.add(nei)) q.offer(new int[]{nei, curr[1] + 1});
        }
    }
    return -1;
}
from collections import deque

def bfs_distance(graph, src, dst):
    visited = {src}
    q = deque([(src, 0)])
    while q:
        node, dist = q.popleft()
        if node == dst: return dist
        for nei in graph.get(node, []):
            if nei not in visited:
                visited.add(nei)
                q.append((nei, dist + 1))
    return -1
Pattern 2 · DFS — Connectivity / Islands

DFS explores as deep as possible before backtracking. Perfect for connected component problems, flood fill, and counting islands. Mark nodes visited before recursing to avoid infinite loops in graphs with cycles.

Grid DFS template: The "mark before recursing" rule is critical. If you mark after recursing, you'll enter the same cell from multiple neighbors and stack overflow. Mark when you first visit — immediately set grid[r][c] = '0' before the recursive calls.

// Number of Islands (LC 200) — DFS flood fill
public int numIslands(char[][] grid) {
    int count = 0;
    for (int r = 0; r < grid.length; r++)
        for (int c = 0; c < grid[0].length; c++)
            if (grid[r][c] == '1') { dfs(grid, r, c); count++; }
    return count;
}

private void dfs(char[][] grid, int r, int c) {
    if (r < 0 || r >= grid.length || c < 0 || c >= grid[0].length
        || grid[r][c] != '1') return;
    grid[r][c] = '0'; // mark visited immediately
    dfs(grid, r+1, c); dfs(grid, r-1, c);
    dfs(grid, r, c+1); dfs(grid, r, c-1);
}
def num_islands(grid):
    rows, cols = len(grid), len(grid[0])
    count = 0

    def dfs(r, c):
        if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] != '1': return
        grid[r][c] = '0'  # mark visited
        dfs(r+1,c); dfs(r-1,c); dfs(r,c+1); dfs(r,c-1)

    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1': dfs(r, c); count += 1
    return count
Pattern 3 · Topological Sort

For directed acyclic graphs (DAGs), topological sort gives a linear ordering of nodes where every edge points forward. Use Kahn's algorithm (BFS with in-degrees) for cycle detection plus ordering.

Cycle detection: After Kahn's algorithm, if the result list contains fewer nodes than the graph, a cycle exists — some nodes never had in-degree 0. This is how LC 207 (Course Schedule) detects impossible orderings.

// Topological Sort — Kahn's BFS algorithm (LC 210)
public int[] findOrder(int n, int[][] prereqs) {
    List<List<Integer>> adj = new ArrayList<>();
    int[] indegree = new int[n];
    for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
    for (int[] p : prereqs) { adj.get(p[1]).add(p[0]); indegree[p[0]]++; }

    Deque<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < n; i++) if (indegree[i] == 0) q.offer(i);

    int[] order = new int[n]; int idx = 0;
    while (!q.isEmpty()) {
        int node = q.poll();
        order[idx++] = node;
        for (int nei : adj.get(node))
            if (--indegree[nei] == 0) q.offer(nei);
    }
    return idx == n ? order : new int[0]; // empty if cycle
}
from collections import deque, defaultdict

def find_order(n, prereqs):
    adj = defaultdict(list)
    indegree = [0] * n
    for a, b in prereqs:
        adj[b].append(a); indegree[a] += 1

    q = deque(i for i in range(n) if indegree[i] == 0)
    order = []
    while q:
        node = q.popleft()
        order.append(node)
        for nei in adj[node]:
            indegree[nei] -= 1
            if indegree[nei] == 0: q.append(nei)
    return order if len(order) == n else []
Pattern 4 · Union-Find (Disjoint Set)

Union-Find efficiently tracks connected components with two operations: find (which component does this belong to?) and union (merge two components). Path compression and union by rank make both operations near-O(1).

class UnionFind {
    int[] parent, rank;

    UnionFind(int n) {
        parent = new int[n]; rank = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
    }

    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]); // path compression
        return parent[x];
    }

    boolean union(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return false; // already connected — cycle!
        if (rank[px] < rank[py]) { int t=px; px=py; py=t; }
        parent[py] = px;
        if (rank[px] == rank[py]) rank[px]++;
        return true;
    }
}
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # path compression
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py: return False  # cycle!
        if self.rank[px] < self.rank[py]: px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]: self.rank[px] += 1
        return True

LC 417 · Pacific Atlantic Water Flow Medium

Find cells that can flow to both the Pacific and Atlantic oceans. The trick: reverse the problem — do BFS/DFS backwards from each ocean's border, then find the intersection.

Reverse thinking: Instead of simulating water flowing downhill from every cell (expensive), start from ocean borders and flood uphill. A cell can reach the Pacific if it's reachable from the Pacific border going uphill. Intersect the two reachable sets.

public List<List<Integer>> pacificAtlantic(int[][] h) {
    int R = h.length, C = h[0].length;
    boolean[][] pac = new boolean[R][C], atl = new boolean[R][C];
    Deque<int[]> pq = new ArrayDeque<>(), aq = new ArrayDeque<>();
    for (int r = 0; r < R; r++) {
        pac[r][0] = atl[r][C-1] = true;
        pq.offer(new int[]{r,0}); aq.offer(new int[]{r,C-1});
    }
    for (int c = 0; c < C; c++) {
        pac[0][c] = atl[R-1][c] = true;
        pq.offer(new int[]{0,c}); aq.offer(new int[]{R-1,c});
    }
    bfs(h, pq, pac); bfs(h, aq, atl);
    List<List<Integer>> res = new ArrayList<>();
    for (int r = 0; r < R; r++)
        for (int c = 0; c < C; c++)
            if (pac[r][c] && atl[r][c]) res.add(Arrays.asList(r, c));
    return res;
}
from collections import deque

def pacific_atlantic(h):
    R, C = len(h), len(h[0])
    def bfs(starts):
        visited = set(starts)
        q = deque(starts)
        while q:
            r, c = q.popleft()
            for dr, dc in [(1,0),(-1,0),(0,1),(0,-1)]:
                nr, nc = r+dr, c+dc
                if 0<=nr<R and 0<=nc<C and (nr,nc) not in visited and h[nr][nc]>=h[r][c]:
                    visited.add((nr,nc)); q.append((nr,nc))
        return visited
    pac = bfs([(r,0) for r in range(R)] + [(0,c) for c in range(C)])
    atl = bfs([(r,C-1) for r in range(R)] + [(R-1,c) for c in range(C)])
    return [[r,c] for r,c in pac & atl]
LC 684 · Redundant Connection Medium

Find the edge that creates a cycle in an undirected graph. Union-Find: if both endpoints of an edge are already in the same component, that edge is the redundant one.

public int[] findRedundantConnection(int[][] edges) {
    int n = edges.length;
    UnionFind uf = new UnionFind(n + 1);
    for (int[] e : edges) {
        if (!uf.union(e[0], e[1])) return e; // union returns false = cycle
    }
    return new int[0];
}
