Dynamic Programming · First Principles Series

Dynamic Programming,
built one question at a time.

This series teaches DP the way people actually internalize it: start with brute force, notice the repeated work, define the state carefully, and then earn the recurrence instead of memorizing it.

Part 1 builds the foundations. Part 2 shifts to min/max optimization. Part 3 introduces richer state and advanced patterns.

Brute force first Memoization to tabulation Count / Min / Max State-machine thinking Java + Python

How to use this track

If DP still feels slippery, don’t jump straight to the hard problems. Work in order and let the question type change only one variable at a time.

  • Part 1: “How many ways?” and “what repeats?”
  • Part 2: “What is cheapest / maximum?” with the same recurrence skeleton
  • Part 3: “What extra state do I need to remember?”

What you’ll practice

  • 1D DP arrays and rolling variables
  • Grid DP and triangle-style dependencies
  • Decision DP: take / skip / restart
  • Stateful DP over strings, colors, and transitions
