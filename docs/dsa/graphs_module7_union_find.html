Union-Find — connectivity without rerunning DFS

DFS and BFS answer connectivity by exploring the graph directly. Union-Find answers a different question: if edges are being added over time, can we track which nodes belong to the same group without traversing everything again and again?

When to reach for it: repeated merge operations, “are these in the same component now?”, redundant edges, account merging, dynamic islands, or any problem where components evolve over time.

Core idea

Every node points to a parent. The root of that parent chain is the representative of the component.

Why it’s fast

Path compression flattens the chain during find, and union by rank/size keeps trees shallow.

The mental model

Think of Union-Find as a family-name system. find(x) tells you which family node x belongs to. union(a, b) merges two families. If find(a) == find(b), they are already in the same component.

Core Template 
class UnionFind {
    int[] parent, rank;

    UnionFind(int n) {
        parent = new int[n];
        rank = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
    }

    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    boolean union(int a, int b) {
        int pa = find(a), pb = find(b);
        if (pa == pb) return false;
        if (rank[pa] < rank[pb]) parent[pa] = pb;
        else if (rank[pb] < rank[pa]) parent[pb] = pa;
        else { parent[pb] = pa; rank[pa]++; }
        return true;
    }
}
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, a, b):
        pa, pb = self.find(a), self.find(b)
        if pa == pb:
            return False
        if self.rank[pa] < self.rank[pb]:
            self.parent[pa] = pb
        elif self.rank[pb] < self.rank[pa]:
            self.parent[pb] = pa
        else:
            self.parent[pb] = pa
            self.rank[pa] += 1
        return True

How to recognize it

Use Union-Find when

You keep merging connections and only need to know whether nodes end up in the same group.

Don’t use it when

You need shortest path, traversal order, or to inspect the exact shape of a component.
