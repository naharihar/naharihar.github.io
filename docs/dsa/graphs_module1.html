THE FORMAL DEFINITION
Chapter 2 of 5

Two ingredients.
Nodes and edges.

Computer scientists gave the "things" a name: nodes (also called vertices). They gave the "connections" a name: edges. That's the entire vocabulary you need to start.

Let's make this concrete. Look at this tiny graph:

A GRAPH WITH 5 NODES AND 5 EDGES

In the graph above: Alice, Bob, Carol, Dave, Eve are the nodes. The lines connecting them are the edges. Alice–Bob is one edge. Alice–Carol is another. And so on.

Tree vs Graph: You said trees feel shaky — here's the key insight. A tree is a graph. Specifically, it's a graph with exactly one path between any two nodes (no cycles, no disconnected parts). Graphs are more general — they can have cycles, multiple paths, or disconnected sections.

Now, the two most important questions you can ask about any graph. Click each to learn:

↔ UNDIRECTED

The edge goes both ways. If A connects to B, then B connects to A.

  • Friendships (mutual)
  • Roads (usually 2-way)
  • Undirected = symmetric
→ DIRECTED

The edge has an arrow. A → B means you can go A to B, but NOT B to A.

  • Instagram follows (one-way)
  • Course prerequisites
  • Directed = asymmetric
UNDIRECTED (LEFT) vs DIRECTED (RIGHT)
UNWEIGHTED

Every edge is the same. Connection either exists or it doesn't.

  • Friend networks
  • "Are these connected?"
  • Hop count = distance
WEIGHTED

Each edge has a cost / distance / time. Not all connections are equal.

  • Road maps (km)
  • Flight prices ($)
  • Network latency (ms)
WEIGHTED GRAPH — NUMBERS ON EDGES ARE DISTANCES

A cycle is a path that starts and ends at the same node. Think of it as a loop. Graphs can have them — trees cannot.

GRAPH WITH A CYCLE — FOLLOW THE HIGHLIGHTED PATH
This matters enormously in algorithms. An algorithm exploring a cyclic graph without tracking visited nodes will loop forever. This is why "have I already been here?" is the first thing every graph algorithm asks.

A graph is connected if you can reach any node from any other node. If some nodes are isolated islands with no path between them, the graph is disconnected — it has multiple connected components.

TWO SEPARATE COMPONENTS — THERE'S NO PATH FROM LEFT TO RIGHT
In problems like "number of islands" or "number of provinces," you're being asked: how many connected components does this graph have?

GRAPH VOCABULARY
Chapter 4 of 5

The five words you'll see everywhere.

Graph problems use a small, specific vocabulary. Learn these five terms and you'll understand what every problem is actually asking.

HOVER OVER A NODE TO SEE ITS DEGREE
Degree — how many edges connect to a node. In the graph above, hover to see each node's degree. High degree = well-connected node.
Path — a sequence of nodes where each consecutive pair is connected by an edge. Alice → Bob → Dave is a path of length 2.
Neighbor — a node directly connected by one edge. Alice's neighbors are Bob and Carol (if they share edges).
Connected Component — a group of nodes where every node can reach every other node. A graph can have multiple components.
Cycle — a path that starts and ends at the same node. A → B → C → A is a cycle of length 3.
