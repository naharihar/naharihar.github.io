This track is tutorial-first. We start by making graphs feel obvious, then build DFS, BFS, cycle detection, topological sort, Union-Find, and Dijkstra through repetition-heavy modules. Core Graph Templates

Adjacency List

Step zero for most graph problems. Build it once and traversal becomes easy.

AdjacencyList.javaJava
List<List<Integer>> graph = new ArrayList<>();
for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
for (int[] edge : edges) {
    int u = edge[0], v = edge[1];
    graph.get(u).add(v);
    graph.get(v).add(u); // remove for directed graphs
}
adjacency_list.pyPython
graph = [[] for _ in range(n)]
for u, v in edges:
    graph[u].append(v)
    graph[v].append(u)  # remove for directed graphs

DFS

Best for reachability, connectivity, and component discovery.

DFS.javaJava
void dfs(int node, List<List<Integer>> graph, boolean[] seen) {
    seen[node] = true;
    for (int nei : graph.get(node)) {
        if (!seen[nei]) dfs(nei, graph, seen);
    }
}
dfs.pyPython
def dfs(node):
    visited.add(node)
    for nei in graph[node]:
        if nei not in visited:
            dfs(nei)

BFS

Best for minimum hops / shortest path in unweighted graphs.

BFS.javaJava
Queue<Integer> q = new ArrayDeque<>();
q.add(start);
seen[start] = true;
while (!q.isEmpty()) {
    int node = q.poll();
    for (int nei : graph.get(node)) {
        if (!seen[nei]) {
            seen[nei] = true;
            q.add(nei);
        }
    }
}
bfs.pyPython
from collections import deque
q = deque([start])
visited = {start}
while q:
    node = q.popleft()
    for nei in graph[node]:
        if nei not in visited:
            visited.add(nei)
            q.append(nei)

Cycle Detection (Directed)

Three-color DFS is the cleanest mental model for prerequisites and dependency graphs.

CycleDirected.javaJava
boolean dfs(int node) {
    if (state[node] == 1) return true;
    if (state[node] == 2) return false;
    state[node] = 1;
    for (int nei : graph.get(node)) {
        if (dfs(nei)) return true;
    }
    state[node] = 2;
    return false;
}
cycle_directed.pyPython
def dfs(node):
    if state[node] == 1: return True
    if state[node] == 2: return False
    state[node] = 1
    for nei in graph[node]:
        if dfs(nei): return True
    state[node] = 2
    return False

Topological Sort (Kahn)

Use this when the problem asks for a valid order under dependencies.

Kahn.javaJava
Queue<Integer> q = new ArrayDeque<>();
for (int i = 0; i < n; i++) if (indegree[i] == 0) q.add(i);
List<Integer> order = new ArrayList<>();
while (!q.isEmpty()) {
    int node = q.poll();
    order.add(node);
    for (int nei : graph.get(node)) {
        if (--indegree[nei] == 0) q.add(nei);
    }
}
topo_sort.pyPython
from collections import deque
q = deque([i for i in range(n) if indegree[i] == 0])
order = []
while q:
    node = q.popleft()
    order.append(node)
    for nei in graph[node]:
        indegree[nei] -= 1
        if indegree[nei] == 0:
            q.append(nei)

Union-Find

Dynamic connectivity when the graph is being merged over time.

UnionFind.javaJava
int[] parent = new int[n], rank = new int[n];
for (int i = 0; i < n; i++) parent[i] = i;
int find(int x) {
    if (parent[x] != x) parent[x] = find(parent[x]);
    return parent[x];
}
boolean union(int a, int b) {
    int pa = find(a), pb = find(b);
    if (pa == pb) return false;
    if (rank[pa] < rank[pb]) parent[pa] = pb;
    else if (rank[pb] < rank[pa]) parent[pb] = pa;
    else { parent[pb] = pa; rank[pa]++; }
    return true;
}
union_find.pyPython
parent = list(range(n))
rank = [0] * n
def find(x):
    if parent[x] != x:
        parent[x] = find(parent[x])
    return parent[x]
def union(a, b):
    pa, pb = find(a), find(b)
    if pa == pb: return False
    if rank[pa] < rank[pb]:
        parent[pa] = pb
    elif rank[pb] < rank[pa]:
        parent[pb] = pa
    else:
        parent[pb] = pa
        rank[pa] += 1
    return True

Dijkstra

Weighted shortest path with a min-heap. Reach for this when BFS is no longer valid.

Dijkstra.javaJava
PriorityQueue<int[]> pq = new PriorityQueue<>((a,b) -> a[1] - b[1]);
pq.add(new int[]{src, 0});
dist[src] = 0;
while (!pq.isEmpty()) {
    int[] cur = pq.poll();
    int node = cur[0], d = cur[1];
    if (d > dist[node]) continue;
    for (int[] edge : graph.get(node)) {
        int nei = edge[0], w = edge[1];
        if (dist[node] + w < dist[nei]) {
            dist[nei] = dist[node] + w;
            pq.add(new int[]{nei, dist[nei]});
        }
    }
}
dijkstra.pyPython
import heapq
pq = [(0, src)]
dist[src] = 0
while pq:
    d, node = heapq.heappop(pq)
    if d > dist[node]:
        continue
    for nei, w in graph[node]:
        nd = d + w
        if nd < dist[nei]:
            dist[nei] = nd
            heapq.heappush(pq, (nd, nei))

Beginner → Mastery Roadmap

STEP 1

Remove fear

Modules 1 and 2 make graphs concrete and implementable. Do not skip them if graph input still freezes you.

STEP 2

Own traversal

Modules 3 and 4 are the foundation. DFS and BFS should become memory, not improvisation.

STEP 3

Recognize patterns

Modules 5 and 6 build the habit of saying the pattern before writing the code.

STEP 4

Advance carefully

Modules 7 and 8 add Union-Find and Dijkstra only after the traversal intuition is stable.

Recommended study rule: do at least two starter reps and one core rep from a module before moving on. If a core problem still feels shaky, repeat the module. Repetition is the point.
