Maximum Earnings From Taxi

This is weighted interval scheduling with a story wrapper. Each ride has a time interval and a value, so the question is whether taking this ride plus the best compatible history beats skipping it.

Official LeetCode problem ↗ Build this from first principles ↗
Problem

Pick a set of non-overlapping rides with maximum total money

Plain-English Statement

Each ride gives a start point, an end point, and a tip. If you take it, you earn the ride distance plus the tip. You can only take one ride at a time.

Return the maximum total earnings you can collect from non-overlapping rides.

Intuition

It is the same pattern as weighted job scheduling

Each ride has:

Ride fieldWeighted-interval meaning
startinterval start
endinterval end
end - start + tipinterval value

So the decision is exactly the same as LC 1235: for each ride, either skip it or take it and add the best earnings from the latest compatible ride before it.

Compatibility lookup Sort rides by end position. Then binary search to find the last ride whose end is <= the current start.
Solution

Sort by end, then DP + binary search on compatible rides

import java.util.*;

class Solution {
    public long maxTaxiEarnings(int n, int[][] rides) {
        Arrays.sort(rides, (a, b) -> Integer.compare(a[1], b[1]));
        int m = rides.length;
        int[] ends = new int[m];
        for (int i = 0; i < m; i++) ends[i] = rides[i][1];

        long[] dp = new long[m];
        dp[0] = rides[0][1] - rides[0][0] + rides[0][2];

        for (int i = 1; i < m; i++) {
            long earn = rides[i][1] - rides[i][0] + rides[i][2];
            int j = upperBound(ends, rides[i][0]) - 1;
            if (j >= 0) earn += dp[j];
            dp[i] = Math.max(dp[i - 1], earn);
        }
        return dp[m - 1];
    }

    private int upperBound(int[] arr, int target) {
        int lo = 0, hi = arr.length;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (arr[mid] <= target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
from bisect import bisect_right

class Solution:
    def maxTaxiEarnings(self, n, rides):
        rides.sort(key=lambda ride: ride[1])
        ends = [ride[1] for ride in rides]
        dp = [0] * len(rides)
        dp[0] = rides[0][1] - rides[0][0] + rides[0][2]

        for i in range(1, len(rides)):
            start, end, tip = rides[i]
            earn = end - start + tip
            j = bisect_right(ends, start) - 1
            if j >= 0:
                earn += dp[j]
            dp[i] = max(dp[i - 1], earn)

        return dp[-1]

O(m log m)

Sort rides, then do one binary search per ride.

For the DP array and sorted ride metadata.
