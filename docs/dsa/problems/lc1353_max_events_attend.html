Maximum Number of Events That Can Be Attended

This looks like interval selection, but you are choosing a specific day for each event. The right greedy move is to attend the event that ends earliest among everything currently available.

Official LeetCode problem ↗ Build this from first principles ↗
Problem

Choose one day per event and attend as many as possible

Plain-English Statement

Each event gives a range of days [startDay, endDay]. You may attend at most one event per day, and if you attend an event, you only need to pick one day inside its range.

Return the maximum number of events you can attend.

Intuition

Sweep day by day and always consume the earliest deadline first

On each day, several events may already be available. If you can attend only one, the safest choice is the event whose end day is smallest, because it is the one that will disappear soonest if you wait.

Day sweep pattern Sort events by start day. As the day increases, push all newly available events into a min-heap of end days. Remove expired events, then attend the event that ends earliest.
Solution

Start-day sweep + min-heap of current deadlines

import java.util.*;

class Solution {
    public int maxEvents(int[][] events) {
        Arrays.sort(events, (a, b) -> Integer.compare(a[0], b[0]));
        PriorityQueue<Integer> heap = new PriorityQueue<>();
        int day = 0, i = 0, attended = 0, n = events.length;

        while (i < n || !heap.isEmpty()) {
            if (heap.isEmpty()) day = Math.max(day, events[i][0]);

            while (i < n && events[i][0] <= day) {
                heap.offer(events[i++][1]);
            }
            while (!heap.isEmpty() && heap.peek() < day) {
                heap.poll();
            }
            if (!heap.isEmpty()) {
                heap.poll();
                attended++;
                day++;
            }
        }
        return attended;
    }
}
import heapq

class Solution:
    def maxEvents(self, events):
        events.sort()
        heap = []
        day = 0
        i = 0
        attended = 0

        while i < len(events) or heap:
            if not heap:
                day = max(day, events[i][0])

            while i < len(events) and events[i][0] <= day:
                heapq.heappush(heap, events[i][1])
                i += 1

            while heap and heap[0] < day:
                heapq.heappop(heap)

            if heap:
                heapq.heappop(heap)
                attended += 1
                day += 1

        return attended
Time
O(n log n)

Each event enters and leaves the heap once.

Space
O(n)

The heap can store all currently available events.
