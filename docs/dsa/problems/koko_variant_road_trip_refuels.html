Road Trip Refuels

Drive across n city legs. Each leg takes a fixed number of miles. Your tank holds k miles. Find the minimum tank size to complete the trip within h refuels.

Problem

What are we solving?

Problem Statement

You drive across n city legs. Leg i is miles[i] long. Your tank holds k miles — you refuel once before each leg if needed, using one refuel stop per leg. Return the minimum tank capacity k such that you can complete all legs in at most h refuel stops.

Example
Inputmiles = [3, 6, 7, 11], h = 8
Output4

k=4: ⌈3/4⌉+⌈6/4⌉+⌈7/4⌉+⌈11/4⌉ = 1+2+2+3 = 8 ≤ 8 ✓. k=3 gives 1+2+3+4=10 > 8 ✗.

Intuition

The answer is a tank size, not an index

Tank size isn't in the array — it's a rate we binary search from 1 to max(miles). For each candidate, we check if total refuel stops ≤ h.

Key insight If tank size k works, k+1 also works. If k fails, k-1 also fails. This monotonic F→T shape is exactly what binary search needs.

The feasibility check

For each road leg, we need ⌈group_size / k⌉ refuel stops. Sum over all road legs and check if total ≤ h. In code: (size + k - 1) / k avoids floating point.

Search bounds Minimum k = 1. Maximum k = max(road legs) — no benefit going higher since even the largest group finishes in one refuel stop.
Solution

Binary search on tank size

class Solution {
    public int minTankSize(int[] miles, int h) {
        int lo = 1, hi = 0, ans = 0;
        for (int m : miles) hi = Math.max(hi, m);
        ans = hi;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (canDrive(miles, mid, h)) { ans = mid; hi = mid - 1; }
            else lo = mid + 1;
        }
        return ans;
    }
    private boolean canDrive(int[] miles, int k, int h) {
        int stops = 0;
        for (int m : miles) stops += (m + k - 1) / k;
        return stops <= h;
    }
}
import math
class Solution:
    def min_tank_size(self, miles, h):
        lo, hi, ans = 1, max(miles), max(miles)
        while lo <= hi:
            mid = lo + (hi - lo) // 2
            if sum(math.ceil(m / mid) for m in miles) <= h:
                ans = mid; hi = mid - 1
            else: lo = mid + 1
        return ans
