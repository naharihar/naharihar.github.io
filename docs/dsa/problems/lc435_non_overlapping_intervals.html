Non-overlapping Intervals

The cleanest starting point for the entire scheduling family. Once you understand why earliest finishing intervals are safest, the rest of the track becomes much easier.

Problem

Remove the fewest intervals so the rest stop colliding

Statement

Given an array of intervals where intervals[i] = [starti, endi], return the minimum number of intervals you need to remove so the remaining intervals are non-overlapping.

Example
Input[ [1,2], [2,3], [3,4], [1,3] ]
Output1
WhyRemove [1,3] and the other three fit without overlap.
Intuition

Keep the interval that frees the timeline earliest

The direct way to think about this problem is not “which interval should I remove?” It is “which intervals should I keep?” If you can keep the maximum number of non-overlapping intervals, then everything else must be removed.

Key reframing minimum removals = total intervals - maximum intervals kept

Now the greedy choice becomes natural. When two intervals compete for the same future time, keeping the one that ends earlier is better because it leaves more room for later intervals.

After sorting by end time, every interval gets a simple yes/no check against the end of the last accepted interval.

Step 1Sort intervals by end time: [1,2], [2,3], [1,3], [3,4].
Step 2Keep [1,2]. It ends earliest.
Step 3[2,3] starts at 2, which is valid, so keep it.
Step 4[1,3] overlaps with the current boundary, so drop it.
Step 5[3,4] starts at 3, so keep it. Kept 3, removed 1.
Solution

Sort by end time and count how many cannot fit

import java.util.Arrays;

class Solution {
    public int eraseOverlapIntervals(int[][] intervals) {
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[1], b[1]));

        int removed = 0;
        int lastEnd = intervals[0][1];

        for (int i = 1; i < intervals.length; i++) {
            if (intervals[i][0] < lastEnd) {
                removed++;
            } else {
                lastEnd = intervals[i][1];
            }
        }
        return removed;
    }
}
class Solution:
    def eraseOverlapIntervals(self, intervals):
        intervals.sort(key=lambda iv: iv[1])

        removed = 0
        last_end = intervals[0][1]

        for start, end in intervals[1:]:
            if start < last_end:
                removed += 1
            else:
                last_end = end

        return removed
