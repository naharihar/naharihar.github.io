Course Schedule III

One of the most elegant scheduling problems: sort by deadline, greedily take courses, and whenever you run out of time, remove the longest course you have taken so far.

Problem

Take the most courses without missing deadlines

Statement

Each course is given as [duration, lastDay]. You must take a course continuously for its duration and finish by lastDay. Return the maximum number of courses you can take.

Input[[100,200],[200,1300],[1000,1250],[2000,3200]]
Output3
Intuition

Always keep the shortest total schedule possible

Sorting by deadline is still the right first move because nearer deadlines constrain you earlier. But simply accepting courses in that order is not enough. A long course can block several short ones that appear later.

Swap insight If your current set of accepted courses is too long to meet the latest deadline, the worst course to keep is the one with the largest duration. Removing it frees the most time while losing only one course.

Solution

Deadline order + max-heap of chosen durations

import java.util.*;

class Solution {
    public int scheduleCourse(int[][] courses) {
        Arrays.sort(courses, (a, b) -> Integer.compare(a[1], b[1]));
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
        int time = 0;

        for (int[] course : courses) {
            time += course[0];
            maxHeap.offer(course[0]);

            if (time > course[1]) {
                time -= maxHeap.poll();
            }
        }
        return maxHeap.size();
    }
}
import heapq

class Solution:
    def scheduleCourse(self, courses):
        courses.sort(key=lambda c: c[1])
        max_heap = []
        time = 0

        for duration, deadline in courses:
            time += duration
            heapq.heappush(max_heap, -duration)

            if time > deadline:
                time += heapq.heappop(max_heap)

        return len(max_heap)
Time
O(n log n)

Sort once, then each course touches the heap.

Space
O(n)

The heap stores chosen course durations.
