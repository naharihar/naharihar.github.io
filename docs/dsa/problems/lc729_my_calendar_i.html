My Calendar I

This is the dynamic version of interval scheduling. Bookings arrive one at a time, so instead of sorting once, you keep the accepted intervals ordered and only inspect the neighbors that could overlap.

Problem

Support online booking without double-booking

Statement

Implement a calendar that supports book(start, end). Return true if the event can be added without overlapping any existing event, otherwise return false.

book(10,20)→ true
book(15,25)→ false
book(20,30)→ true
Intuition

In sorted order, only the neighbors can cause trouble

If accepted bookings are sorted by start time, a new booking only needs to compare against the next booking and the previous booking around its insertion point. Anything farther away starts even later or ends even earlier, so it cannot newly overlap.

Human version When someone asks for a new reservation, you do not scan the entire hotel history. You look at the booking that ends just before the requested time and the booking that starts just after it.
Existing sorted bookingsNew requestNeed to check
[10,20], [30,40][20,30]Fits exactly between both neighbors
[10,20], [30,40][15,18]Overlaps previous booking
[10,20], [30,40][32,35]Overlaps next/containing booking
Solution

Maintain ordered starts and inspect only insertion neighbors

import java.util.TreeMap;

class MyCalendar {
    private TreeMap<Integer, Integer> map = new TreeMap<>();

    public boolean book(int start, int end) {
        Integer prev = map.floorKey(start);
        if (prev != null && map.get(prev) > start) {
            return false;
        }

        Integer next = map.ceilingKey(start);
        if (next != null && next < end) {
            return false;
        }

        map.put(start, end);
        return true;
    }
}
from bisect import bisect_left

class MyCalendar:
    def __init__(self):
        self.events = []

    def book(self, start: int, end: int) -> bool:
        i = bisect_left(self.events, (start, end))

        if i > 0 and self.events[i - 1][1] > start:
            return False
        if i < len(self.events) and self.events[i][0] < end:
            return False

        self.events.insert(i, (start, end))
        return True
Time
O(log n)

TreeMap lookup in Java. Python list insertion is O(n), but the overlap check is neighbor-only.

Space
O(n)

You store all accepted events.
