LC 2136 Pattern 1 variant Hard

Earliest Possible Day of Full Bloom

Each plant’s grow time runs in parallel after planting, so the right question is: which seeds should start their long waiting period as early as possible?

Official LeetCode problem ↗ Build this from first principles ↗
Problem

Order the planting so the last flower blooms as early as possible

Plain-English Statement

Each seed takes some number of days to plant and then some number of days to grow. You can plant only one seed per day, but once a seed is planted, its growing happens in parallel while you keep planting other seeds.

Return the earliest day when every flower has bloomed.

Intuition

Start the long growers first

If a flower needs a very long grow time, delaying its planting also delays the day its long parallel wait can even begin. So long-grow flowers should be planted earlier, not later.

Ordering rule Sort seeds by growTime in descending order. Then accumulate planting time, and after each seed compute plantingSoFar + growTime. The maximum of those is the answer.
Solution

Sort by grow time descending, then track the latest bloom day

import java.util.*;

class Solution {
    public int earliestFullBloom(int[] plantTime, int[] growTime) {
        int n = plantTime.length;
        int[][] seeds = new int[n][2];
        for (int i = 0; i < n; i++) {
            seeds[i] = new int[] {plantTime[i], growTime[i]};
        }
        Arrays.sort(seeds, (a, b) -> Integer.compare(b[1], a[1]));

        int planted = 0;
        int answer = 0;
        for (int[] seed : seeds) {
            planted += seed[0];
            answer = Math.max(answer, planted + seed[1]);
        }
        return answer;
    }
}
class Solution:
    def earliestFullBloom(self, plantTime, growTime):
        seeds = sorted(zip(plantTime, growTime), key=lambda item: -item[1])
        planted = 0
        answer = 0

        for plant, grow in seeds:
            planted += plant
            answer = max(answer, planted + grow)

        return answer
Time
O(n log n)

Sorting the seeds dominates.

Space
O(n)

For the paired list of seeds.
