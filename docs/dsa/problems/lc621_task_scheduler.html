Task Scheduler

This problem feels like time-slot simulation, but the fastest solution comes from counting the task that forces the schedule to be longest.

Official LeetCode problem ↗ Build this from first principles ↗
Problem

Run all tasks while respecting cooldown gaps

Plain-English Statement

You have tasks represented by capital letters. The same task type must wait at least n time units before it can run again.

Each time unit can execute one task or stay idle. Return the minimum total number of time units needed to finish every task.

Original Example
Inputtasks = ["A","A","A","B","B","B"], n = 2
Output8
WhyOne optimal order is A B idle A B idle A B.
Intuition

The most frequent task creates the schedule frame

If one task appears very often, it forces gaps between its copies. Those gaps define the minimum schedule width you must provide.

Frame idea If the most frequent task appears maxFreq times, you can think of placing those copies first. They create maxFreq - 1 gaps, and each gap must hold at least n other time units between copies.

The resulting formula is:

Counting Formula
answer = max(totalTasks, (maxFreq - 1) * (n + 1) + countOfMaxFreqTasks)

The max matters because sometimes there are enough other tasks to fill every idle slot completely.

Solution

Count frequencies instead of simulating the whole schedule

class Solution {
    public int leastInterval(char[] tasks, int n) {
        int[] freq = new int[26];
        for (char task : tasks) freq[task - 'A']++;

        int maxFreq = 0;
        for (int count : freq) maxFreq = Math.max(maxFreq, count);

        int countMax = 0;
        for (int count : freq) {
            if (count == maxFreq) countMax++;
        }

        int frame = (maxFreq - 1) * (n + 1) + countMax;
        return Math.max(tasks.length, frame);
    }
}
from collections import Counter

class Solution:
    def leastInterval(self, tasks, n):
        freq = Counter(tasks)
        max_freq = max(freq.values())
        count_max = sum(1 for value in freq.values() if value == max_freq)

        frame = (max_freq - 1) * (n + 1) + count_max
        return max(len(tasks), frame)
Time
O(n)

Just count frequencies and scan 26 task types.

Space
O(1)

The alphabet size is fixed.
