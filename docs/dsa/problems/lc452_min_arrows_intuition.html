First Principles

How to think about balloon arrows without memorizing the trick

The leap here is to realize the arrow itself is just a point representing an entire overlap cluster of intervals.

Human Version

One arrow can service one overlapping group

Real picture

Each balloon occupies a horizontal range. If several ranges overlap, one carefully placed arrow can burst all of them at once.

So the true problem is: how many overlap groups do these intervals form if you place each arrow optimally?

Brute Force

The naive approach is to reason about arrow positions directly

You might try guessing where to shoot, checking which balloons that arrow hits, removing them, and then repeating. The issue is that the arrow position feels continuous and overly flexible.

Simplifying observation You never need to shoot at a random point. The only meaningful candidates are boundary points created by balloon ends.
Optimization

The earliest finishing balloon gives the safest arrow position

Sort by end coordinate. The first balloon to finish forces your hand: any arrow that wants to burst it must land on or before its right edge, so placing the arrow exactly there is the safest choice for also hitting later balloons.
