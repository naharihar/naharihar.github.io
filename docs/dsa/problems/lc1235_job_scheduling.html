LC 1235 Pattern 4 Hard

Maximum Profit in Job Scheduling

This is the weighted version of interval scheduling. Greedy alone stops working because the best answer depends on profit, not just how many jobs fit.

Official LeetCode problem ↗ Build this from first principles ↗
Problem

Pick a non-overlapping set of jobs with maximum total profit

Plain-English Statement

You are given arrays startTime, endTime, and profit. Each job occupies a time range [start, end).

You may take any set of non-overlapping jobs. Return the maximum total profit possible.

Original Example
Inputstart = [1,2,3,3], end = [3,4,5,6], profit = [50,10,40,70]
Output120
WhyThe best plan is taking the jobs worth 50 and 70 because their time ranges do not overlap.
Intuition

At each job, choose between skipping it or taking it

Once jobs are sorted by end time, each job has only two meaningful choices:

ChoiceValue
Skip this jobKeep the best profit found so far
Take this jobThis profit plus the best compatible profit before it
Why greedy fails here A short low-profit job that ends early is not always better than a slightly longer high-profit job. The objective is value, so we need dynamic programming.

The binary-search part is only there to locate the last job that ends before the current one starts.

Solution

Sort by end time, then use DP plus binary search for compatibility

import java.util.*;

class Solution {
    public int jobScheduling(int[] startTime, int[] endTime, int[] profit) {
        int n = startTime.length;
        int[][] jobs = new int[n][3];

        for (int i = 0; i < n; i++) {
            jobs[i] = new int[] {startTime[i], endTime[i], profit[i]};
        }
        Arrays.sort(jobs, (a, b) -> Integer.compare(a[1], b[1]));

        int[] ends = new int[n];
        for (int i = 0; i < n; i++) {
            ends[i] = jobs[i][1];
        }

        int[] dp = new int[n];
        dp[0] = jobs[0][2];

        for (int i = 1; i < n; i++) {
            int include = jobs[i][2];
            int j = upperBound(ends, jobs[i][0]) - 1;
            if (j >= 0) {
                include += dp[j];
            }
            dp[i] = Math.max(dp[i - 1], include);
        }

        return dp[n - 1];
    }

    private int upperBound(int[] ends, int target) {
        int lo = 0, hi = ends.length;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (ends[mid] <= target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
from bisect import bisect_right

class Solution:
    def jobScheduling(self, startTime, endTime, profit):
        jobs = sorted(zip(startTime, endTime, profit), key=lambda job: job[1])
        ends = [job[1] for job in jobs]
        dp = [0] * len(jobs)
        dp[0] = jobs[0][2]

        for i, (start, end, money) in enumerate(jobs[1:], start=1):
            include = money
            j = bisect_right(ends, start) - 1
            if j >= 0:
                include += dp[j]
            dp[i] = max(dp[i - 1], include)

        return dp[-1]
Time
O(n log n)

Sorting plus one binary search per job.

Space
O(n)

The DP array and sorted job list both scale with input size.
