Maximum Profit in Job Scheduling

This is the weighted version of interval scheduling. The greedy “take earliest finish” rule is no longer enough, so we pair interval ordering with dynamic programming and binary search.

Problem

Pick a non-overlapping set of jobs with maximum total profit

Statement

You are given arrays startTime, endTime, and profit. Each job takes time [start, end). Return the maximum total profit you can earn from non-overlapping jobs.

Inputstart=[1,2,3,3], end=[3,4,5,6], profit=[50,10,40,70]
Output120
Intuition

At each job, choose between taking it or skipping it

Sort jobs by end time. For each job, there are only two meaningful choices:

ChoiceValue
Skip this jobBest profit up to the previous job
Take this jobThis job’s profit + best profit ending before this job starts

The second term is where binary search enters. Once jobs are sorted by end time, we can quickly locate the last job whose end time is less than or equal to the current start time.

Why greedy fails here A short low-profit job that ends early is not always better than a slightly longer but much higher-profit job. We need DP because the objective is value, not count.
Solution

Sort by end time, then use DP + binary search for compatibility

import java.util.*;

class Solution {
    public int jobScheduling(int[] startTime, int[] endTime, int[] profit) {
        int n = startTime.length;
        int[][] jobs = new int[n][3];

        for (int i = 0; i < n; i++) {
            jobs[i] = new int[] {startTime[i], endTime[i], profit[i]};
        }
        Arrays.sort(jobs, (a, b) -> Integer.compare(a[1], b[1]));

        int[] ends = new int[n];
        for (int i = 0; i < n; i++) ends[i] = jobs[i][1];

        int[] dp = new int[n];
        dp[0] = jobs[0][2];

        for (int i = 1; i < n; i++) {
            int include = jobs[i][2];
            int j = upperBound(ends, jobs[i][0]) - 1;
            if (j >= 0) include += dp[j];
            dp[i] = Math.max(dp[i - 1], include);
        }
        return dp[n - 1];
    }

    private int upperBound(int[] ends, int target) {
        int lo = 0, hi = ends.length;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (ends[mid] <= target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}
from bisect import bisect_right

class Solution:
    def jobScheduling(self, startTime, endTime, profit):
        jobs = sorted(zip(startTime, endTime, profit), key=lambda job: job[1])
        ends = [job[1] for job in jobs]
        dp = [0] * len(jobs)
        dp[0] = jobs[0][2]

        for i in range(1, len(jobs)):
            include = jobs[i][2]
            j = bisect_right(ends, jobs[i][0]) - 1
            if j >= 0:
                include += dp[j]
            dp[i] = max(dp[i - 1], include)

        return dp[-1]
Time
O(n log n)

Sorting plus a binary search for each job.

Space
O(n)

For the DP array and sorted jobs.
