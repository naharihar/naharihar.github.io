Exam Scheduling

Binary search the number of hours; EDF (Earliest Deadline First) greedily schedules students at each hour. Two classic algorithms meet.

Problem

What are we solving?

Problem Statement

A school has n students. Student i is available only during the window [start[i], end[i]] (hours, 0-indexed). The school has r exam rooms, each holds one student per hour. Find the minimum number of hours T (a contiguous block [0, T-1]) so that every student gets exactly one exam slot within their availability window.

Example
n students5
windows[[0,2],[0,1],[1,3],[2,4],[3,4]]
r (rooms)2
Output4

With T=4 (hours 0..3) and 2 rooms: hour 0 → students 0,1  |  hour 1 → student 2  |  hour 2 → student 3  |  hour 3 → student 4. All scheduled. T=3 is infeasible.

Intuition

Binary search T; EDF schedules each hour

For a given T, can all students be scheduled in hours 0..T-1 with r rooms per hour? This is a classic scheduling feasibility check.

The feasibility is monotone: if T hours are enough, T+1 are also enough. Binary search finds the boundary.

At T=4: all 5 students can be assigned to hours 0..3 with 2 rooms. Answer = 4.

The feasibility check: EDF (Earliest Deadline First)

For a given T, scan hour by hour from 0 to T-1. At each hour h, all students available at hour h (i.e. start[i] ≤ h ≤ end[i]) are candidates. Among unscheduled candidates, greedily assign up to r students with the earliest deadline (smallest end[i]) first.

This is the EDF (Earliest Deadline First) algorithm — a classical result that provably minimizes deadline misses. A student whose deadline is closest should be scheduled before a student with a later deadline.

Why EDF is optimal for feasibility If any valid schedule exists for time T, EDF will find one. Swapping a later-deadline student into an earlier slot cannot help — but swapping an earlier-deadline student into the earliest possible slot can only help (it frees later slots for others). EDF always makes the greedy-correct choice.

Solution

Binary search on T, EDF feasibility check

import java.util.*;

public class Solution {

    public int minHours(int[][] windows, int r) {
        int n = windows.length;
        int lo = 1, hi = n;   // at most n hours needed (1 per student)

        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (canSchedule(windows, r, mid)) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }

    private boolean canSchedule(int[][] windows, int r, int T) {
        // min-heap ordered by deadline (end time)
        PriorityQueue<int[]> active = new PriorityQueue<>(
            (a, b) -> a[1] - b[1]);
        // sort students by start time so we add them as hours pass
        int[][] sorted = windows.clone();
        Arrays.sort(sorted, (a, b) -> a[0] - b[0]);

        int idx = 0, scheduled = 0;
        for (int h = 0; h < T; h++) {
            // add all students whose window starts at or before h
            while (idx < sorted.length && sorted[idx][0] <= h)
                active.offer(sorted[idx++]);
            // remove students whose deadline has already passed
            while (!active.isEmpty() && active.peek()[1] < h)
                active.poll();
            // schedule up to r students with the earliest deadline
            for (int slot = 0; slot < r && !active.isEmpty(); slot++) {
                active.poll();
                scheduled++;
            }
        }
        return scheduled == windows.length;
    }

    public static void main(String[] args) {
        Solution sol = new Solution();
        int[][] windows = {{0,2},{0,1},{1,3},{2,4},{3,4}};
        System.out.println(sol.minHours(windows, 2));  // 4
    }
}
import heapq
from typing import List

class Solution:
    def min_hours(self, windows: List[List[int]], r: int) -> int:
        n = len(windows)
        lo, hi = 1, n

        while lo < hi:
            mid = lo + (hi - lo) // 2
            if self.can_schedule(windows, r, mid):
                hi = mid
            else:
                lo = mid + 1
        return lo

    def can_schedule(self, windows, r, T):
        # sort by start time; min-heap on deadline
        sorted_w = sorted(windows, key=lambda x: x[0])
        heap = []   # (deadline, student_index)
        idx, scheduled = 0, 0

        for h in range(T):
            # add students whose window starts at or before h
            while idx < len(sorted_w) and sorted_w[idx][0] <= h:
                heapq.heappush(heap, sorted_w[idx][1])  # push deadline
                idx += 1
            # evict students whose deadline has passed
            while heap and heap[0] < h:
                heapq.heappop(heap)
            # schedule r earliest-deadline students
            for _ in range(r):
                if not heap: break
                heapq.heappop(heap)
                scheduled += 1

        return scheduled == len(windows)


if __name__ == "__main__":
    s = Solution()
    windows = [[0,2],[0,1],[1,3],[2,4],[3,4]]
    print(s.min_hours(windows, 2))  # 4

Space
O(n)
Heap holds at most n students at once.
Search bounds Lower bound = 1 (must open at least 1 hour). Upper bound = n (worst case: every student has a unique hour, r=1). Could tighten to ceil(n/r) but n is safe and simple.
