Minimum Number of Arrows to Burst Balloons

This is interval scheduling in disguise. Each arrow is one point, and your job is to let one point cover as many overlapping balloon ranges as possible before you fire the next one.

Official LeetCode problem ↗ Build this from first principles ↗
Problem

Cover all balloon ranges with as few cut points as possible

Plain-English Statement

Each balloon is an interval [xstart, xend]. One arrow shot at position x bursts every balloon whose interval contains x.

Return the minimum number of arrows needed to burst all balloons.

Original Example
Inputpoints = [[10,16],[2,8],[1,6],[7,12]]
Output2
WhyOne arrow can hit the overlapping cluster around [1,6] and [2,8]; a second arrow is needed for the later interval.
Intuition

Use one arrow for each overlap cluster

If you sort balloons by where they end, the earliest ending balloon tells you the safest place to fire the current arrow. That point is guaranteed to burst that balloon and still has the best chance of hitting later overlapping balloons too.

Same greedy as LC 435 Instead of keeping an interval, you keep one shooting position. The current arrow location is simply the end boundary of the current overlap cluster.
Cluster View
new arrow only if nextStart > currentArrowPosition
[1,6]
[2,8]
arrow @ 6
[7,12]
new arrow

As long as the next balloon starts before the current arrow position, it can be burst by the same shot.

Solution

Sort by end coordinate and start a new arrow only when overlap breaks

import java.util.Arrays;

class Solution {
    public int findMinArrowShots(int[][] points) {
        Arrays.sort(points, (a, b) -> Integer.compare(a[1], b[1]));

        int arrows = 1;
        int currentEnd = points[0][1];

        for (int i = 1; i < points.length; i++) {
            if (points[i][0] > currentEnd) {
                arrows++;
                currentEnd = points[i][1];
            }
        }

        return arrows;
    }
}
class Solution:
    def findMinArrowShots(self, points):
        points.sort(key=lambda p: p[1])

        arrows = 1
        current_end = points[0][1]

        for start, end in points[1:]:
            if start > current_end:
                arrows += 1
                current_end = end

        return arrows
Time
O(n log n)

Sorting dominates the linear scan.
