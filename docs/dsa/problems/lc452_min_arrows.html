Minimum Number of Arrows to Burst Balloons

This is interval scheduling in disguise. Each arrow is just one carefully chosen point that covers a whole overlapping group of balloons.

Problem

Cover all balloon ranges with as few cut points as possible

Statement

Each balloon is an interval [xstart, xend]. One arrow shot at position x bursts every balloon whose interval contains x. Return the minimum number of arrows needed to burst all balloons.

Example
Input[[10,16],[2,8],[1,6],[7,12]]
Output2
Intuition

Keep one arrow for each overlapping cluster

Once you sort by end coordinate, the best place to shoot an arrow for the current cluster is the earliest ending balloon’s right edge. That point is guaranteed to hit that balloon and has the best chance of still hitting the next ones.

Same greedy as LC 435 The arrow position is just the “last kept end” boundary from interval scheduling, expressed as a point instead of a selected interval.
Cluster view
[1,6]
Arrow at 6 hits
[2,8]
Same arrow
[7,12]
Needs new arrow
Solution

Sort by end and start a new arrow only when overlap breaks

import java.util.Arrays;

class Solution {
    public int findMinArrowShots(int[][] points) {
        Arrays.sort(points, (a, b) -> Integer.compare(a[1], b[1]));

        int arrows = 1;
        int currentEnd = points[0][1];

        for (int i = 1; i < points.length; i++) {
            if (points[i][0] > currentEnd) {
                arrows++;
                currentEnd = points[i][1];
            }
        }
        return arrows;
    }
}
class Solution:
    def findMinArrowShots(self, points):
        points.sort(key=lambda p: p[1])

        arrows = 1
        current_end = points[0][1]

        for start, end in points[1:]:
            if start > current_end:
                arrows += 1
                current_end = end

        return arrows
Time
O(n log n)

Sorting dominates.

Space
O(1)

Ignoring sort space.
