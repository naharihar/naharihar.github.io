Meeting Rooms III

This is resource assignment with two priorities at once: always use the smallest available room id, and when none are free, wait for the room that becomes available first.

Official LeetCode problem ↗ Build this from first principles ↗
Problem

Assign every meeting to a room and count which room gets used most

Plain-English Statement

You have n meeting rooms, numbered 0 to n - 1, and a list of meetings.

Each meeting wants the earliest possible start. If multiple rooms are free, use the smallest-numbered one. If no room is free, delay the meeting until the earliest room becomes free, while keeping the same duration.

Return the room id that hosted the most meetings.

Intuition

You need one heap for free rooms and one for busy rooms

This problem mixes two different priorities, so one heap is not enough.

HeapSorted byPurpose
availableroom idPick the smallest-numbered free room
busyend time, then room idKnow which room frees up first
Core move Before processing a meeting, release every busy room whose end time is already <= the meeting start. If no room is free after that, take the earliest-finishing busy room, delay the meeting to that end time, and push it back with its new end.
Solution

Sort meetings by start time and simulate room state with two heaps

import java.util.*;

class Solution {
    public int mostBooked(int n, int[][] meetings) {
        Arrays.sort(meetings, (a, b) -> Integer.compare(a[0], b[0]));
        PriorityQueue<Integer> available = new PriorityQueue<>();
        PriorityQueue<long[]> busy = new PriorityQueue<>((a, b) ->
            a[0] == b[0] ? Long.compare(a[1], b[1]) : Long.compare(a[0], b[0]));
        int[] used = new int[n];

        for (int i = 0; i < n; i++) available.offer(i);

        for (int[] meeting : meetings) {
            long start = meeting[0], end = meeting[1];
            long duration = end - start;

            while (!busy.isEmpty() && busy.peek()[0] <= start) {
                available.offer((int) busy.poll()[1]);
            }

            if (available.isEmpty()) {
                long[] room = busy.poll();
                start = room[0];
                available.offer((int) room[1]);
                while (!busy.isEmpty() && busy.peek()[0] == start) {
                    available.offer((int) busy.poll()[1]);
                }
            }

            int roomId = available.poll();
            used[roomId]++;
            busy.offer(new long[] {start + duration, roomId});
        }

        int answer = 0;
        for (int i = 1; i < n; i++) {
            if (used[i] > used[answer]) answer = i;
        }
        return answer;
    }
}
import heapq

class Solution:
    def mostBooked(self, n, meetings):
        meetings.sort()
        available = list(range(n))
        busy = []
        used = [0] * n

        for start, end in meetings:
            duration = end - start

            while busy and busy[0][0] <= start:
                _, room = heapq.heappop(busy)
                heapq.heappush(available, room)

            if not available:
                free_time, room = heapq.heappop(busy)
                start = free_time
                heapq.heappush(available, room)
                while busy and busy[0][0] == start:
                    _, room = heapq.heappop(busy)
                    heapq.heappush(available, room)

            room = heapq.heappop(available)
            used[room] += 1
            heapq.heappush(busy, (start + duration, room))

        return max(range(n), key=lambda room: used[room])
Time
O(m log n)

Each meeting touches the heaps a constant number of times.

Space
O(n)

The room heaps store at most all rooms.
